# ZUNO Minimal Landing Page

A minimal, responsive four-panel landing page concept for ZUNO.

## Files
- `index.html` — page content and Font Awesome icons
- `style.css` — layout and responsive styles
- `main.js` — touch swipe, desktop mouse drag, keyboard and slide navigation
- `food.mp4` — add your own video file with this exact name beside `index.html`

## Notes
- The palette is black, white and red, with the WhatsApp icon in its familiar green.
- A subtle SWIPE UP hint appears only on the home panel. Navigate by swiping/dragging, keyboard arrows, or the small slide indicators. Text selection and native dragging are disabled to protect the gesture.
- Font family: Arial. Font Awesome is loaded from a CDN, so icons require an internet connection.
- Replace the example WhatsApp number (`966500000000`) and social profile links with official brand accounts.
- The location link is a Google Maps search, not a real verified ZUNO branch.
- ZUNO is a fictional brand concept.
